## Copy-ready version

**DSA Sprint — Full-Stack DSA Practice Tracker** | React, Redux Toolkit, Spring Boot, PostgreSQL, Docker

- Built a JWT-authenticated practice tracker with per-user problem logs, algorithm notes, POTD streaks, and a yearly activity heatmap.
- Designed a Spring Boot REST API with JPA entities, repository/service/controller layers, and PostgreSQL persistence.
- Created a React dashboard with Redux Toolkit and Axios, including a spaced review queue with 7-day and 14-day reminders.
- Containerized the local stack with Docker Compose and added GitHub Actions build workflows for the frontend and API.

**Repository:** https://github.com/licherover9000/dsa-sprint
