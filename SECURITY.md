# Security policy

DSA Sprint is a learning project and is not yet a hosted service for real user data. Do not use real passwords or sensitive personal information while running an unreviewed deployment.

If you find a security issue, please report it privately through GitHub's **Report a vulnerability** option on this repository's **Security** tab. Avoid posting exploit details in a public issue.

Before a real public launch, review the [public launch checklist](docs/PUBLIC_LAUNCH.md).
